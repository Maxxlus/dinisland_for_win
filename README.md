# Dynamic Island for Windows

Dynamic Island в стиле Apple для Windows: время и статус музыки в капсуле, раскрытие при наведении, шторка с виджетами, буфер обмена, ИИ-чат (OpenRouter), таймер, полка файлов, календарь и погода, VPN-кнопка (v2rayTun / Incy / Happ).

## Как получить exe
**Способ 1 (без установки чего-либо):** вкладка **Actions** → последний запуск `build` → **Artifacts** → `DynamicIsland-win-x64`.
Чтобы появился релиз с exe, создайте тег: `git tag v1.0 && git push origin v1.0`.

**Способ 2 (локально):** установите .NET 8 SDK (`winget install Microsoft.DotNet.SDK.8`) и запустите `build.bat`. Результат: `publish\DynamicIsland.exe`.

## Управление
- Наведите курсор — остров раскроется. `Ctrl+Alt+I` — раскрыть/свернуть с клавиатуры.
- Нажмите на время в раскрытом острове — опустится шторка.
- Остров можно перетащить по горизонтали; позиция запоминается (трей → «Сбросить позицию»).
- Настройки (API-ключ OpenRouter, модель, город, VPN-клиент) — вкладка с шестерёнкой. Конфиг: `%AppData%\DynamicIsland\config.json`.

## VPN
Кнопка в шторке запускает выбранный клиент и пытается нажать в нём «Подключить/Отключить» через UI Automation. Если у клиента кнопки недоступны для автоматизации, задайте свои команды в `config.json`: `VpnConnectCmd` и `VpnDisconnectCmd`.
